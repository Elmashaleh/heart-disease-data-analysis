# Heart Disease Data Analysis & Preprocessing

## Overview

This project explores and preprocesses the **UCI Cleveland Heart Disease Dataset** using Python and common data science libraries.

The objective is to understand the dataset, investigate relationships between variables, handle missing values, and prepare the data for potential downstream machine learning applications.

The project focuses on **exploratory data analysis (EDA) and preprocessing**, rather than training or deploying a heart disease prediction model.

## Dataset

- **Source:** UCI Machine Learning Repository — Heart Disease Dataset
- **Records:** 303
- **Variables:** 14
- **Domain:** Healthcare data analysis

Dataset reference: https://archive.ics.uci.edu/dataset/45/heart+disease

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Project Workflow

### 1. Data Exploration
- Inspected the dataset structure and variables.
- Explored the distribution of features.
- Investigated relationships and correlations between variables.

### 2. Data Cleaning
- Identified and handled missing values.
- Applied preprocessing techniques to improve data consistency.

### 3. Feature Engineering
- Prepared relevant features for analysis.
- Applied feature transformations where appropriate.

### 4. Data Standardization
- Standardized numerical features as part of the preprocessing workflow.
- Prepared the dataset for potential future machine learning experiments.

## How to Run

1. Download or clone this repository.
2. Open the project notebook in Jupyter Notebook or Google Colab.
3. Install the required Python libraries if necessary.
4. Make sure the dataset is available at the path expected by the notebook.
5. Run the notebook cells in order.

## Project Scope

This is an academic data analysis and preprocessing project.

**No heart disease prediction classifier was trained or deployed as part of this work.**

The analysis is intended for educational purposes and should not be used for medical diagnosis or clinical decision-making.
